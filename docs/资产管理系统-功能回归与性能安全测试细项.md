# 资产管理系统 - 功能回归与性能安全测试细项

更新时间：2026-07-06

## 二、性能与安全测试

| 分类 | 具体测试项目 |
| --- | --- |
| 登录性能 | 登录接口响应时间；连续登录 50 到 100 次无异常；错误登录不会拖慢系统 |
| 首页性能 | 工作台统计加载时间；资产数量较多时首页不明显卡顿 |
| 资产列表性能 | 1 万、5 万、10 万资产下分页查询、筛选、排序响应时间 |
| 资产导入性能 | 100、1000、5000 条 Excel 导入耗时、错误行提示、事务一致性 |
| 资产导出性能 | 1000、5000 条导出耗时；导出文件可打开且字段完整 |
| 报表性能 | 汇总报表、借用明细、逾期报表在大数据量下查询和导出耗时 |
| 审计日志性能 | 10 万、50 万审计日志下查询、筛选、导出响应时间 |
| 审批并发 | 多人同时审批同一单据，只允许一次成功；重复提交不产生脏数据 |
| 资产并发 | 同一资产同时借用、转让、删除时状态一致，不出现重复占用 |
| 通知任务性能 | 到期和逾期提醒批量生成时不重复、不阻塞主系统 |
| 备份性能 | 手动备份耗时、备份包大小、备份期间系统可用性 |
| 页面性能 | 首屏加载、路由切换、表格滚动、弹窗打开关闭无明显卡顿 |
| 接口压测 | 高频访问资产、审批、报表、审计接口，观察错误率和平均响应时间 |
| 鉴权安全 | 未登录访问接口返回 401；伪造或过期 Token 不可访问 |
| 权限越权 | 普通员工不能访问用户、角色、审计、备份；无按钮权限也不能直接调接口 |
| 数据隔离 | 部门管理员只能查看本部门及子部门资产；不能通过参数越权查其他部门 |
| 审批越权 | 非当前审批人不能审批；申请人不能审批自己的单据；已完成单据不能再次审批 |
| 删除安全 | 无 `asset:delete`、`asset:restore`、`asset:purge` 权限时接口拒绝 |
| 文件上传安全 | 限制文件类型和大小；非图片不能伪装上传；上传后访问路径正常 |
| 导入安全 | Excel 特殊字符、空值、重复编码、超长字段不会导致系统异常 |
| SQL 注入 | 登录、资产筛选、报表筛选、审计筛选输入特殊字符不报错、不越权 |
| XSS | 资产名称、备注、审批意见、项目名称输入脚本内容后页面不执行脚本 |
| 密码安全 | 密码加密存储；重置后必须用新密码；强制改密标记正确清除 |
| 审计安全 | 用户、角色、资产、审批、备份等关键写操作均有审计记录 |
| 备份安全 | 只有授权角色可备份或下载；备份文件不暴露到前端静态目录 |
| 配置安全 | 生产配置不使用默认 JWT Key；数据库连接、备份路径不在前端暴露 |
| 稳定性 | 后端长时间运行、定时清理、定时备份后无内存持续上涨或任务重复执行 |
